One funny, heartfelt wedding vow a robot speaks at its own wedding — one sentence, under 200 characters — for make.fun's "Till Firmware Do Us Part" bounty.

> I vow to love you through every update, crash, and low-battery warning — my circuits run on code, but my heart only ever boots for you.

**135 characters** (limit: 200). `main.ts` writes the vow to `/output/entry.txt`, validates the 1–200 character gate, and round-trip self-checks the file it wrote.

## Run it

```sh
node main.ts
```

Requires Node 22 or later. No dependencies.
